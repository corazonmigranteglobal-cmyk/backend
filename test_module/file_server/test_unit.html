GCS Tester (Frontend)

Esto llama endpoints de tu backend para probar: ensureUserFolders, uploadBufferAtPath, getSignedReadUrlByPath, existsByPath, deleteByPath, listPaths, copyByPath, moveByPath y download/stream.

Configuración

1) Crear jerarquía de carpetas (ensureUserFolders)

Creará placeholders .keep para que se vean “carpetas” en consola.

2) Subir archivo a ruta específica (uploadBufferAtPath)

Recomendación: prueba con users/{userId}/profile/avatar.jpg y luego con media.

3) Signed URL (getSignedReadUrlByPath)

Si el archivo es imagen/video, se abrirá en otra pestaña.

4) Exists / Delete (existsByPath / deleteByPath)

5) Listar por prefijo (listPaths)

6) Copy / Move (copyByPath / moveByPath)

7) Descargar vía tu backend (stream/download)

Esto prueba tu endpoint de descarga (no signed url).
